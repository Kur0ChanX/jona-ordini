Bolla di consegna · 3 strade

Foto fatta dal cameriere → letta dall'IA → anomalie a Maurizio
1 · Ovvia — tutto nel telefono
📷 foto→salvata nel telefono→l'IA legge (telefono)→riprova ogni 2 min
  • Semplice: riusa Cantina (bozza + «rileggila tu»)
  • iPhone: con l'app chiusa NON riprova nulla
  • Android: in background solo a tratti
2 · Furba — il server legge
📷 foto→invio al server (3 s)→il server legge con l'IA→risultato nell'app
  • Il telefono può chiudersi subito
  • Serve un deposito nuovo sul server (foto + stato)
  • Più codice e più cose che si possono rompere
3 · Geniale — legge chi è acceso
📷 foto→salvata nel telefono
+ in coda sul cloud (2 s)→la legge il primo
dispositivo aperto
(tablet cucina, Maurizio…)→risultato a tutti
  • Foto mai persa: telefono + cloud
  • Riprova finché va, anche con il telefono del cameriere chiuso
  • Niente server nuovo: usa il cloud che c'è già
  • Se nessun dispositivo è aperto, legge al primo che si apre
Consiglio: 3 Geniale (+ in tutte: IA 2.5 Flash senza «ragionamento», più tempo per le foto)
