## 2. Taglia-foto: crea `tools/taglia-foto.py` con questo contenuto (serve Pillow: `python3 -c "import PIL"`)
```python
#!/usr/bin/env python3
"""Taglia una foto lunga in pezzi leggibili sul telefono (C90, Mario #116).

Perché: il visualizzatore riduce una foto alta (es. 780×6400) per farla entrare nello schermo, e il testo diventa
illeggibile. Pezzi alti al massimo ~1100 px a larghezza piena restano chiari.

Uso: python3 -I tools/taglia-foto.py <foto.png> [cartella-uscita] [altezza-massima]
Scrive <nome>-1di3.png, <nome>-2di3.png… e stampa i percorsi (uno per riga). Taglia negli spazi vuoti
(le righe più uniformi vicino al punto di taglio), mai in mezzo al testo. Non cancella niente.
"""
import sys
from pathlib import Path

from PIL import Image

ALTEZZA = 1100   # px massimi per pezzo (foto a 2x di un telefono: poco più di mezza schermata alta)
FINESTRA = 0.2   # il taglio si cerca entro il 20% dell'altezza prima del punto ideale

def riga_vuota(img, y):
    """Più basso = riga più uniforme (spazio vuoto). Misura la differenza tra il pixel più chiaro e più scuro."""
    riga = img.crop((0, y, img.width, y + 1)).convert('L')
    lo, hi = riga.getextrema()
    return hi - lo

def punti_di_taglio(img, massimo):
    tagli = [0]
    while img.height - tagli[-1] > massimo:
        ideale = tagli[-1] + massimo
        minimo = tagli[-1] + int(massimo * (1 - FINESTRA))
        migliore = min(range(minimo, ideale + 1), key=lambda y: (riga_vuota(img, y), -y))
        tagli.append(migliore)
    tagli.append(img.height)
    return tagli

def main():
    if len(sys.argv) < 2:
        print(__doc__)
        return 1
    foto = Path(sys.argv[1])
    uscita = Path(sys.argv[2]) if len(sys.argv) > 2 else foto.parent
    massimo = int(sys.argv[3]) if len(sys.argv) > 3 else ALTEZZA
    uscita.mkdir(parents=True, exist_ok=True)
    img = Image.open(foto).convert('RGB')
    if img.height <= massimo * 1.15:
        print(foto)  # già abbastanza bassa: niente da tagliare
        return 0
    tagli = punti_di_taglio(img, massimo)
    n = len(tagli) - 1
    for i in range(n):
        pezzo = img.crop((0, tagli[i], img.width, tagli[i + 1]))
        p = uscita / f'{foto.stem}-{i + 1}di{n}.png'
        pezzo.save(p)
        print(p)
    return 0

if __name__ == '__main__':
    sys.exit(main())
```
Uso: `python3 -I tools/taglia-foto.py <foto.png> <cartella-uscita>` → stampa i percorsi dei pezzi.

## 4. Prove su GitHub saltate per i soli documenti (solo se il progetto ha un file `.github/workflows/*.yml` con prove)
Ok di Mario già dato in RVC; qui chiedigli un tocco se il tuo controllo di sicurezza blocca la modifica. Aggiungi come PRIMO passo del job questo (cambia `prove.yml` col nome del tuo file, e le cartelle «solo documenti» se diverse) e aggiungi `if: steps.doc.outputs.salta != 'true'` a ogni passo successivo tranne l'eventuale caricamento del rapporto con `if: failure()`:
```yaml
      # C87 (ok di Mario, #117): se rispetto all'ultimo push sono cambiati SOLO documenti (docs/, archivio/, .claude/,
      # file .md in cima) e l'ultimo giro sul commit di prima era VERDE, il giro non si rifà: il lavoro si chiude subito, verde.
      # In ogni altro caso (codice toccato, giro di prima rosso o mancante, qualsiasi dubbio) gira tutto.
      - name: Solo documenti? Riuso l'esito del giro di prima
        id: doc
        env:
          GH_TOKEN: ${{ github.token }}
          REPO: ${{ github.repository }}
          PRIMA: ${{ github.event.before }}
          DOPO: ${{ github.event.pull_request.head.sha || github.sha }}
        run: |
          salta=false
          if [ -n "$PRIMA" ] && [ -n "${PRIMA//0/}" ] && [ "$GITHUB_EVENT_NAME" != "schedule" ] && [ "$GITHUB_EVENT_NAME" != "workflow_dispatch" ]; then
            file=$(gh api "repos/$REPO/compare/$PRIMA...$DOPO" --jq '[.files[].filename] | join(" ")' 2>/dev/null || echo "")
            solo_doc=false
            if [ -n "$file" ]; then
              solo_doc=true
              for f in $file; do
                case "$f" in docs/*|archivio/*|.claude/*) ;; */*) solo_doc=false ;; *.md) ;; *) solo_doc=false ;; esac
              done
            fi
            if [ "$solo_doc" = true ]; then
              esito=$(gh api "repos/$REPO/actions/workflows/prove.yml/runs?head_sha=$PRIMA&status=completed&per_page=5" --jq '.workflow_runs[0].conclusion // ""' 2>/dev/null || echo "")
              echo "Solo documenti. Esito del giro sul commit di prima: '$esito'"
              if [ "$esito" = "success" ]; then salta=true; fi
            fi
          fi
          echo "salta=$salta" >> "$GITHUB_OUTPUT"
          if [ "$salta" = true ]; then echo "::notice::Solo documenti dopo un giro verde: prove non rifatte (C87)."; fi
```

Regola di sicurezza: se cambia codice, o il giro prima non era verde, o c'è qualsiasi dubbio → il giro gira intero. Mai saltare in modo semplice.
